How I work

Every campaign runs the same loop, so each launch is quicker and better informed than the last.

  1. 01

    Plan the request

    Marketing requests get prioritized by impact and timing, so the most important campaign always ships first.

    Jira, Trello, Google Sheets

  2. 02

    Build the campaign

    Landing pages in Builder.io, GetSiteControl banners and pop-ups, product page updates and on-brand Mailchimp templates.

    Builder.io, GetSiteControl, Mailchimp

  3. 03

    Check and send

    Pre-send checks on links, merge tags and formatting, plus speed and responsiveness checks against Core Web Vitals.

    Measure and improve

    Page performance and A/B test results show what worked, and those learnings shape the next campaign.

    Mixpanel, Microsoft Clarity, VWO
